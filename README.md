- `python3 tools/build.py` writes `docs/index.html`, `docs/th/`, `docs/km/`; all copy lives in it, three languages side by side.
- `docs/weave.js` draws everything that moves: the loom hero weaving the shawl, the draft, ikat, friezes, satin, formula cloth, cocoon, Silk Road map.
- `python3 tools/serve.py` serves `docs/` on port 8891. `?card` renders the 1200 × 630 share card (headless Chrome, window 1200 × 760, crop to 630).
